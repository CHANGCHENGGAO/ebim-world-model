四、评委意见

优点

  • 功能完整: 四阶段全自主运行，16/16 官方满分，无人工介入
  • 鲁棒性好: 视觉误检防瞬移、IK 重试、超时降级等多层保护机制
  • 技术创新: YOLO 视觉 + LLM 本地规划 + Diffusion Policy 框架，可选模块不干扰主流程
  • 兜底可靠: 四层降级链验证通过，LLM 超时后硬编码自动接管，0 次失败
  • 工程规范: Dockerfile + README + 技术报告齐全，GitHub 公开仓库

不足

  • 提交类型错误: 当前以 Technical Report (0.65x) 提交，应升级为 Repository Submission (1.0x)，直接损失 35% 权重
  • 提交内容过时: Issue #22 写 "not yet trained"，实际已有 18/18 自主控制器
  • Stage 2 双臂协调缺失: 官方要求一手持勺一手稳碗，当前仅用左臂（过程指标，不影响得分）
  • 安全监控未实现: 头部力阈值检测（ISO/TS 15066）未部署（仿真阶段不强制，真机阶段必须）
